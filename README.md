# Claude con Carpetas — versiones

Aquí se publican los instaladores de **Claude con Carpetas**, el programa de Windows que agrega carpetas y
subcarpetas visuales al menú lateral de Claude.

- **Instalar:** descarga el instalador de la rama [`descargas`](../../tree/descargas)
  (`Claude-con-Carpetas-Setup-x.y.z.exe`) y ábrelo.
- **Actualizar:** no hace falta hacer nada. El programa revisa la rama `descargas` al abrirse y cada 4 horas,
  descarga la versión nueva en segundo plano y la instala al cerrarse (o al instante con "Reiniciar").

Este repositorio solo contiene las versiones publicadas; no tiene el código fuente.
